## Go Environment

**Installation path**: ~/local/go (Go 1.26.3)

**Installation date**: 2026-05-22

**Usage**: Add to PATH before building:
```bash
export PATH=$HOME/local/go/bin:$PATH
```

**Note**: sing-box 1.13.x requires Go 1.24.7+, Go 1.26.3 is compatible.
